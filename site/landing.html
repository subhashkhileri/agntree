Run every coding agent without leaving VS Code.

Agntree is a sidebar for your Claude Code, Codex, opencode, and Pi sessions and git worktrees. No separate app to install, no second window to keep an eye on. It works in VS Code and Cursor.

Your agents belong where your code is

Most agent managers are a separate desktop app: another install, another window, another set of shortcuts to learn. You already spend the day in your editor. Agntree is an extension, so nothing about how you work has to change.

Nothing new to install

One extension from the Marketplace. No desktop app, no account, and nothing to configure.

Your editor, untouched

Your theme, extensions, keybindings, and terminal stay as they are. Agents run in VS Code's own terminal, in each agent's own CLI.

Review where you write

The diff, the file tree, and source control are already here. Read what an agent changed in the same place you would fix it.

Everything around the agent, one click away

Agntree groups every session under the repository and branch it runs in.

Agents are editor tabs

Each session is an ordinary tab. Drag it, split it, and watch two agents work side by side like any two files. How sessions work →
